# Sales Intelligence & Business Performance Analytics Platform

## Project Overview
A data analytics project built using MySQL and Microsoft Power BI to analyse sales performance, customer behaviour, product profitability and regional business trends.

## Tools & Technologies
- MySQL 8.0
- SQL
- Microsoft Power BI
- DAX
- VS Code

## Database Structure
The project uses five relational tables:
- Regions
- Customers
- Products
- Orders
- Order Items

## Key Analysis Areas
- Overall revenue and profit performance
- Monthly sales trends
- Product and category performance
- Regional sales analysis
- Customer segmentation and repeat purchases
- Sales channel contribution
- Profit margin and average order value

## Power BI Dashboard
The dashboard contains four analytical sections:
1. Executive Overview
2. Product Analysis
3. Customer Intelligence
4. Regional Analysis

## Business Metrics
- Total Revenue
- Total Profit
- Total Orders
- Total Customers
- Profit Margin
- Average Order Value

## Dataset
This project uses synthetic sales data created for educational and portfolio purposes.

## Project Objective
To demonstrate practical SQL querying, data analysis, business intelligence reporting and dashboard development skills.
